# OpticTrace Homebrew tap

```bash
brew install dwarka-prasad/tap/optictrace
```

[OpticTrace](https://github.com/dwarka-prasad/optictrace) is a declarative API
telemetry and governance gateway — one `optic.yaml` controls what your API
traffic reveals.

The formula covers macOS and Linux, on both Intel and ARM. It is regenerated
from each release's published `checksums.txt` by
[`scripts/update-tap.sh`](https://github.com/dwarka-prasad/optictrace/blob/main/scripts/update-tap.sh),
so the hashes here always match the artifacts you actually download.
